# Displays

Finds the displays that show part of the desktop, with each one's model, mode, scale and
connection, and gives each one an identifier that stays the same from one run to the next,
like `KXGR16`. A program's `"Display"` setting and `--display` argument name a display by it.
[IdentifyDisplays](../../Program/IdentifyDisplays/README.md) shows each display's identifier
on that display, and explains how identifiers are made.
