# WindowsApiRaw

The Windows API bindings that every Rust package in KGames uses, in one crate, so that a
type like `HWND` or `ID3D12Device` is the same type in all of them.

The bindings in `src/bindings.rs` are generated by
[`windows-bindgen`](https://crates.io/crates/windows-bindgen), with `bindings-generator`, and
committed, so that building a program never compiles the generator: only `Test/WindowsApi`
depends on it, to check the file. Their only dependency is Microsoft's [`windows-core`](https://crates.io/crates/windows-core)
crate.

This package holds only what `windows-bindgen` generates. What KGames adds to the bindings, like
`check_handle`, is in [Library/windows-api](../windows-api/README.md). `Test/WindowsApi` checks
both: that `src/bindings.rs` is exactly what `bindings-generator` writes, that nothing else is in
this package, and that no bindings are in WindowsApi.

## Using more APIs

1. Add the API's native name to `bindings-generator/Filters.txt`.
   For a method that an interface inherits, name the base interface, like `IDXGISwapChain::Present`.
2. Regenerate `src/bindings.rs`, from anywhere in the repository:

   ```powershell
   cargo run -p bindings-generator
   ```

3. Commit `Filters.txt` and `bindings.rs` together.

GameInput isn't in the Windows metadata that `windows-bindgen` reads, so its bindings are
written by hand in [Library/game-input-raw](../game-input-raw/README.md) instead.

## Layout

| Path                             | Contents                                           |
| -------------------------------- | -------------------------------------------------- |
| `src/lib.rs`                     | Exports the bindings                               |
| `src/bindings.rs`                | Generated Windows API bindings; don't edit by hand |
| `bindings-generator/Filters.txt` | The Windows APIs to generate bindings for          |
| `bindings-generator/src/lib.rs`  | Runs `windows-bindgen` to write the bindings       |
| `bindings-generator/src/main.rs` | Writes them to `src/bindings.rs`                   |
