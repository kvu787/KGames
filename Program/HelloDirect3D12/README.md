# HelloDirect3D12

A minimal Rust program that opens a Win32 window and draws a triangle with Direct3D 12.

Its only dependency is Microsoft's [`windows-core`](https://crates.io/crates/windows-core) crate,
which brings in three small crates of its own.
The Windows API bindings in `Source/Bindings.rs` are generated by
[`windows-bindgen`](https://crates.io/crates/windows-bindgen) and committed,
so normal builds don't compile the generator.
Shaders are compiled to DXIL at build time by `dxc.exe` from the Windows SDK.

## Requirements

- Rust with the `x86_64-pc-windows-msvc` toolchain
- Windows SDK (provides `dxc.exe` under `C:\Program Files (x86)\Windows Kits\10\bin\<version>\x64`)
- Optional, for the D3D12 debug layer in debug builds: the "Graphics Tools" optional Windows feature

## Build and run

```powershell
cargo run --release
```

## Using more Windows APIs

1. Add the API's native name to `BindingsGenerator/Filters.txt`.
   For a method that an interface inherits, name the base interface, like `IDXGISwapChain::Present`.
2. Regenerate `Source/Bindings.rs`:

   ```powershell
   cargo run --manifest-path BindingsGenerator/Cargo.toml
   ```

3. Commit `Filters.txt` and `Bindings.rs` together.

## Layout

| Path                                | Contents                                                          |
| ----------------------------------- | ----------------------------------------------------------------- |
| `Source/Main.rs`                    | Window, message loop, and the Direct3D 12 renderer                |
| `Source/Bindings.rs`                | Generated Windows API bindings; don't edit by hand                |
| `Shaders/Triangle.hlsl`             | Vertex and pixel shaders, plus the embedded root signature        |
| `Build.rs`                          | Finds the newest Windows SDK `dxc.exe` and compiles shaders       |
| `BindingsGenerator/Filters.txt`     | The Windows APIs to generate bindings for                         |
| `BindingsGenerator/Source/Main.rs`  | Runs `windows-bindgen` to write `Source/Bindings.rs`              |
